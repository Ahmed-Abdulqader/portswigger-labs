### Quick Start with BlindSQLi.py

**Automate blind SQL injection labs in 3 steps:**

```bash
# 1. Navigate to the sql-injection directory
cd sql-injection

# 2. Run the automation script
python3 BlindSQLi.py

# 3. Follow the prompts:
#    - Enter lab URL
#    - Enter session cookie
#    - Enter tracking ID
```

**Supported Labs:**
- ✅ Lab 11: Blind SQL injection with conditional responses
- ✅ Lab 12: Blind SQL injection with conditional errors
- ✅ Lab 14: Blind SQL injection with time delays
- ✅ Lab 15: Blind SQL injection with time delays and information retrieval

**Features:**
- Binary search optimization (7 requests per character vs 95 with brute force)
- Automatic password extraction
- Support for multiple injection techniques
- Clean, interactive CLI
